mcp-skills-vault

A deterministic registry + integrity scanner for MCP servers, so installing one stops feeling like curl | bash.

Install

npx -y @froggychips/mcp-vault scan --cwd ./my-project
npx -y @froggychips/mcp-vault list
npx -y @froggychips/mcp-vault audit --json
npx -y @froggychips/mcp-vault verify --offline
npx -y @froggychips/mcp-vault doctor

What this does NOT do

  • Not a sandbox. Installing an MCP server still runs that server with the permissions of your MCP host.
  • Not a runtime monitor. Vault gates install-time metadata; use trace or other tooling to observe runtime behaviour.
  • Not proof that a server is benign. Hashes prove you got the artifact you expected, not that the artifact is safe.

  "heavy": [
    { "name": "mcp-atlassian", "est_tools_count": 72 }

}

audit --json reports installed drift without reading token values:

{
  "counts": { "drift": 1, "untrusted": 0, "heavy-unbounded": 1 },
  "findings": [
    {
      "category": "heavy-unbounded",
      "server": "github",
      "message": "100 tools and no --toolsets / allowedTools scope"
    }
  ]
}
