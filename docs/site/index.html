Tools for taming the MCP supply chain.

Two small, offline-first tools for people who run Model Context Protocol servers on their own machines and want to know what those servers are doing.

mcp-skills-vault

Install MCP safely: a curated registry with pinned hashes, license info, and advisory checks before install.

Learn about vault →

mcp-trace

See what MCP servers are doing after install: local stdio proxy, SQLite metadata, bodies off by default.

Trace repo →

Why these two together

  • Vault answers what to install: integrity-pinned commands before npx -y runs.
  • Trace answers what it is doing: tool calls, latency, errors, and token-cost estimates.
  • Neither sends anything off your machine. Network checks are additive, not required for the local gate.
