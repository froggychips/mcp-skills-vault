Install in 5 minutes

1. Scan your project

npx -y @froggychips/mcp-vault scan --cwd .

2. Check local readiness

npx -y @froggychips/mcp-vault doctor

3. Verify the vault DB without network

npx -y @froggychips/mcp-vault verify --offline

4. Audit installed MCP servers

npx -y @froggychips/mcp-vault audit --strict

5. Check what your hosts actually launch

The DB is one thing; the servers your editor starts are another. This reads .mcp.json, ~/.claude.json, Claude Desktop, Cursor, VS Code and Codex, and reports unpinned launch commands, servers that aren't in the vault, and remote endpoints as what they are.

npx -y @froggychips/mcp-vault verify --installed

6. See what they cost in context

Every enabled server injects its whole tool list into the system prompt, on every request.

npx -y @froggychips/mcp-vault budget
